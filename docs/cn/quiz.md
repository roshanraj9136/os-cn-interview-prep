# CN Mock Quiz

Ye 25 questions ka full CN mock test hai, saare topics se: basics, OSI/TCP-IP, data link, IP/subnetting, routing, TCP/UDP, application layer aur security. Isme 5 numerical questions bhi hai (subnet, delay, CRC, window).

Test lene ka tarika:

- 20 minute ka timer lagao, notes band rakho, ek baar mein poora karo.
- Har question pehle khud socho, phir option chuno.
- Score dekhne ke baad galat wale topics ki detail page phir se padho.
