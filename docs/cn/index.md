# Computer Networks: Roadmap

Computer Networks (CN) matlab: do ya zyada computers aapas mein jude hue, taaki wo data share kar sakein. Aapka WhatsApp message, YouTube video, Google search - sab network ke upar chalta hai.

Socho ek courier system (Blue Dart, DTDC jaisa). Aapko ek parcel bhejna hai. Aap address likhte ho, parcel pack karte ho, courier company usko hub se hub tak bhejti hai, aur aakhir mein wo sahi ghar pahunch jaata hai. Network bilkul aisa hi kaam karta hai: data ko chhote packets mein tod ke, address (IP) laga ke, ek device se doosre device tak pahunchaya jaata hai.

Is roadmap page par aapko pata chalega: CN interview mein kaise aata hai, kaun sa topic pehle padhna hai, aur har page ko kaise use karna hai.

## Interview mein CN kaise aata hai

CN teen jagah puchha jaata hai:

- **Online Assessment (OA) MCQs:** OSI layers, port numbers, TCP vs UDP, subnetting numericals, CRC. Speed aur accuracy dono chahiye.
- **Technical round:** OSI model, TCP 3-way handshake, DNS, HTTP vs HTTPS, firewall, "difference between X and Y" type questions.
- **The famous question:** "What happens when you type google.com and press Enter?" - ye lagbhag har jagah puchha jaata hai. Iske liye [google.com walk-through](/cn/google-com) page hai.

## Sirf 2 ghante hain? Ye 10 topics pehle

Agar interview kal hai, to ye 10 cheezein zaroor padho:

1. [OSI aur TCP/IP Model](/cn/osi-tcpip) - 7 layers aur kaun sa protocol kahan.
2. [TCP vs UDP](/cn/tcp-udp) - difference aur kab kaun sa.
3. [TCP 3-way handshake](/cn/tcp-udp) - SYN, SYN-ACK, ACK.
4. [IP Addressing aur Subnetting](/cn/ip-addressing) - network/broadcast address nikalna.
5. [Data Link Layer](/cn/data-link) - MAC vs IP, switch kaise kaam karta hai.
6. [ARP](/cn/data-link) - IP se MAC kaise milta hai.
7. [DNS](/cn/application-layer) - naam se IP kaise milta hai.
8. [HTTP vs HTTPS](/cn/application-layer) - aur status codes.
9. [Hub vs Switch vs Router](/cn/basics) - kaun si layer, kya kaam.
10. [google.com walk-through](/cn/google-com) - sab kuch jodne wala sawaal.

## Har page ko kaise use karein

Teen step follow karo:

1. **Padho:** Hinglish explanation aur example dhyaan se padho. Jaldi mat karo.
2. **Bolo:** Har "Interview mein aise bolo" box ko English mein zor se bol ke practice karo. Interview English mein hota hai, isliye bolna zaroori hai.
3. **Quiz:** Page ke end mein "Quick Quiz" solve karo. Galti ho to upar wapas jaa ke padho.
