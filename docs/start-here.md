# Yahan se shuru karo

Agar aapko OS aur CN mein abhi kuch nahi aata, to bilkul theek hai. Ye site isi soch ke saath bani hai. Is page mein 5 minute mein samjho ki interview mein ye subjects kaise aate hain, aur is site ko kaise use karna hai.

## Ye site kis ke liye hai

- B.Tech / MCA students jo campus ya off-campus placement ki taiyaari kar rahe hain.
- Target: 12-15 LPA wali companies, jaise banks ki tech teams (Wells Fargo, Barclays, IDFC First Bank), networking companies (Nokia, NetCracker, NetGear), product/software companies (BMC, Ansys, PubMatic, Brillio, Epsilon) aur premium tracks (Infosys Specialist Programmer, TCS Prime). Real data [Companies](/companies) page par hai.
- Jinko concepts samajhne hain, sirf ratne nahi.

## Interview mein OS aur CN kahan aata hai

| Round | Kya hota hai | Kaise taiyaari karein |
|---|---|---|
| Online assessment (OA) | DSA coding ke saath OS, CN, DBMS ke MCQs. Kabhi chhote numericals (scheduling, page faults, subnetting). | Har page ka Quick Quiz aur dono Mock Quiz |
| Technical interview | "Process vs thread kya hai?", "Deadlock kya hai?", "TCP vs UDP?", "google.com type karne par kya hota hai?" | "Interview mein aise bolo" boxes bol ke practice karo |
| Follow-up questions | Interviewer aapke answer se agla sawaal banata hai: "Zombie process kaise hataoge?", "DNS UDP kyun use karta hai?" | Har page ke "Follow-up" boxes |

## Har topic page ka format

Har page ek hi pattern follow karta hai, taaki aapko pata rahe kya kahan milega:

1. **Simple explanation** Hinglish mein, roz ki life ke example ke saath.
2. **Diagram aur table**: "X vs Y" wale sawaal sabse zyada aate hain, isliye har difference table mein hai.
3. **Interview mein aise bolo**: 2-4 line ka English answer. Ise 2-3 baar zor se bolo.
4. **Common galti**: jo galti zyada log karte hain.
5. **Follow-up**: interviewer ka agla sawaal aur uska chhota answer.
6. **Yaad rakhne layak points** aur **Quick Quiz**.

::: info Explanation Hinglish mein, answer English mein kyun?
Samajhna apni bhasha mein sabse aasan hota hai. Par interview English mein hota hai, isliye har "Interview mein aise bolo" box simple English mein likha hai. Pehle Hinglish se samjho, phir English answer bol ke practice karo.
:::

## Answer dene ka simple formula

Koi bhi theory sawaal ho, answer is order mein do:

1. **Definition**: ek line mein kya hai.
2. **Example**: ek chhota real example.
3. **Difference ya trade-off**: kis cheez se alag hai, ya fayda/nuksaan.
4. **Real use** (agar yaad ho): kahan use hota hai.

Example: "What is a deadlock?"

::: tip Interview mein aise bolo
A deadlock is a situation where two or more processes wait for each other forever, because each one holds a resource that the other needs. For example, process A holds the printer and waits for the scanner, while process B holds the scanner and waits for the printer. It can happen only when four conditions hold together: mutual exclusion, hold and wait, no preemption and circular wait. We can prevent it by breaking any one of them, for example by always acquiring locks in a fixed order.
:::

Ye answer 25-30 second ka hai. Interviewer ko ismein definition, example aur solution teeno mil gaye. Ab wo follow-up poochega, aur wahi aapka mauka hai.

## Agar answer nahi aata

- Bluff mat karo. Interviewer turant pakad leta hai.
- Jo pata hai wahan se shuru karo: "I am not fully sure, but I think it works like this..."
- Sochte hue bolo (think aloud). Interviewer aapki thinking dekhna chahta hai, sirf final answer nahi.
- Galti ho jaaye to maan lo aur sudhaar do. Ye achha signal hai.

## Common galtiyan jo log karte hain

| Galti | Kya karein |
|---|---|
| Rata hua lamba paragraph bolna | 2-4 line bolo, phir interviewer ko poochne do |
| Terms mix karna (process/program, mutex/semaphore) | Har page ki "vs" table ek baar likh ke dekho |
| Sirf definition dena | Ek example zaroor do |
| Numericals mein formula yaad, method nahi | Ek worked example khud paper par dobara solve karo |
| Answer ke beech mein ruk jaana | Pehle "Interview mein aise bolo" box 2-3 baar zor se bolo |
