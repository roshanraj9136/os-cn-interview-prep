# OS Mock Quiz

Ye ek full mock test hai: 25 questions jo poore Operating System syllabus se aaye hain, bilkul online assessment (OA) jaise. Isme 5 numerical questions bhi hain (scheduling, Banker's, page faults, paging address, fork).

Test kaise dein:
- 20 minute ka timer laga lo, no notes, no Google.
- Pehle poora soch ke answer chuno, phir submit karke explanation padho.
- 20/25 se upar score achha hai; neeche aaye to kamzor topic revise karo.
